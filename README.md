# 🚦 Quiz de Trânsito

Aplicativo mobile desenvolvido em **Android Studio** com o objetivo de apresentar um quiz educativo sobre conhecimentos e regras de trânsito.

## 📌 Sobre o projeto

O **Quiz de Trânsito** é uma aplicação desenvolvida como projeto acadêmico para praticar o desenvolvimento de aplicativos Android.

A aplicação apresenta perguntas relacionadas ao trânsito, permitindo que o usuário escolha uma alternativa e avance pelo quiz.

O projeto também trabalha conceitos de **interface gráfica, navegação entre telas, interação com o usuário e programação em Java**.

## 🎯 Objetivo

Criar um aplicativo simples e interativo para testar os conhecimentos do usuário sobre trânsito, ao mesmo tempo em que são aplicados conceitos aprendidos durante o curso de **Análise e Desenvolvimento de Sistemas**.

## 🛠️ Tecnologias utilizadas

- ☕ Java
- 📱 Android Studio
- 🎨 XML
- 🔧 Git e GitHub

## ⚙️ Funcionalidades

- ▶️ Início do quiz
- ❓ Exibição de perguntas sobre trânsito
- 🔘 Seleção de alternativas
- 📊 Verificação das respostas
- 🏆 Sistema de pontuação
- 🔄 Navegação entre as perguntas
- 📱 Interface adaptada para aplicativo Android

## 🎨 Interface

O aplicativo possui uma interface simples e intuitiva, utilizando elementos visuais relacionados ao tema de trânsito.

Entre os elementos utilizados estão:

- Logo do aplicativo
- Título do quiz
- Perguntas
- Botões de resposta
- Área de pontuação
- Botões de navegação

## 📚 O que foi praticado

Durante o desenvolvimento do projeto foram praticados conceitos como:

- Desenvolvimento de aplicações Android
- Criação de layouts utilizando XML
- Programação em Java
- Manipulação de componentes da interface
- Eventos de clique
- Navegação entre telas
- Organização de um projeto no Android Studio
- Utilização do Git e GitHub para versionamento

## 👩‍💻 Desenvolvimento

Projeto desenvolvido durante a graduação em **Análise e Desenvolvimento de Sistemas (ADS)**.

O desenvolvimento também proporcionou experiência prática com a criação de interfaces Android e implementação da lógica de funcionamento de um quiz.
